# Carlita

**Carlita** — помічник для Discord із підтримкою інтеграції Twitch. Проєкт створений для надання корисних інструментів і функцій Discord-спільнотам.

Проєкт перебуває на етапі активної розробки. Основна увага приділяється надійності, зручності використання та поступовому розширенню можливостей.

## Можливості

- Інструменти для керування Discord-серверами.
- Інтеграція з Twitch.
- Сповіщення про початок трансляцій.
- Відображення інформації про трансляції.
- Збереження історії трансляцій.

## Мова

Наразі Carlita підтримує українську мову. Підтримку англійської мови заплановано на майбутнє.

## Доступність

На поточному етапі Carlita використовується в обмеженому режимі та додається вручну до вибраних Discord-серверів.

Публічне запрошення може стати доступним у майбутньому.

## Умови роботи

Carlita наразі працює на локальному обладнанні розробника. Її доступність залежить від електропостачання, інтернет-з'єднання та працездатності обладнання.

Безперервна робота сервісу наразі не гарантується.

## Вартість

Carlita є безкоштовним проєктом. Наразі вона не має платних функцій або підписок.

# Carlita

**Carlita** is a Discord assistant with Twitch integration. The project aims to provide useful tools and features for Discord communities.

The project is currently under active development, with a focus on reliability, ease of use, and gradually expanding its functionality.

## Features

- Discord server management utilities.
- Twitch integration.
- Live stream notifications.
- Stream information display.
- Stream history tracking.

## Language

Carlita currently supports Ukrainian. English language support is planned for the future.

## Availability

At this stage, Carlita is available in a limited capacity and is manually added to selected Discord servers.

Public invitations may become available in the future.

## Operating Conditions

Carlita currently runs on the developer's local hardware. Its availability depends on power supply, internet connectivity, and the proper functioning of the equipment.

Continuous service availability is not currently guaranteed.

## Cost

Carlita is a free project. It currently has no paid features or subscriptions.
